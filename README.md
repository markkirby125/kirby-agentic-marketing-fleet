# Agentic Marketing Fleet

Autonomous multi-agent AI marketing agency fleet for Claude Code, Gemini CLI, and Antigravity. Dispatches 5 context-isolated parallel subagents to audit websites across messaging, conversion rate optimization (CRO), competitive intel, technical SEO, and growth strategy, compiling publication-grade client PDF deliverables in under 2 minutes.

### 🪄 The Magic Prompt
Copy and paste this into any AI coding app (Cursor, Windsurf, Claude Code, Grok, Kimi, Reasonix, Gemini CLI):

```markdown
@agent Install the Agentic Marketing Fleet skill from: https://github.com/markkirby125/kirby-agentic-marketing-fleet
1. Read `SKILL.md` and `references/` from the repository.
2. Place into your environment's skills/rules directory preserving the dispatcher structure.
3. Confirm when installation is complete.
```
